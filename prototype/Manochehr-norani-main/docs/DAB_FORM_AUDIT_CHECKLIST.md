# DAB Form Audit Checklist

Use this checklist before merging any DAB form consolidation.

- [ ] Form title checked.
- [ ] All sections preserved.
- [ ] All fields preserved.
- [ ] Required documents preserved.
- [ ] Declarations and undertakings preserved.
- [ ] Validation rules preserved.
- [ ] Official DAB source checked.
- [ ] Canonical registry entry checked.
- [ ] Legacy route checked.
- [ ] Duplicate implementation confirmed unused before removal.
- [ ] DAB registry verification passes.
- [ ] DAB route verification passes.
- [ ] Architecture verification passes.
- [ ] Lint and type checks pass.
- [ ] Production build passes.
