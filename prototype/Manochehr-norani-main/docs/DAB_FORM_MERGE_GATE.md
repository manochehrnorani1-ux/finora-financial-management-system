# DAB Form Merge Gate

A DAB form consolidation can be merged only when all of the following are true:

- [ ] Complete content comparison is done.
- [ ] No required field was lost.
- [ ] No required section was lost.
- [ ] Required documents are preserved.
- [ ] Declarations are preserved.
- [ ] Official DAB source is recorded.
- [ ] Canonical route is working.
- [ ] Old route is handled safely.
- [ ] Duplicate code is confirmed unused.
- [ ] DAB registry verification passes.
- [ ] DAB route verification passes.
- [ ] Architecture verification passes.
- [ ] Lint and type checks pass.
- [ ] Production build passes.

If any item is not confirmed, do not remove the old implementation.
